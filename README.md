# 📊 Pizza Sales Analysis Using MySQL

## 📘 Overview

The Pizza Sales Analysis project aims to analyze pizza sales data using MySQL to uncover valuable business insights such as sales trends, most popular pizzas, revenue distribution, and category-wise performance.
The project covers all levels of SQL query implementation — Basic, Intermediate, and Advanced — to demonstrate practical knowledge of SQL concepts including joins, aggregate functions, CTEs, window functions, and data grouping.

## 🎯 Project Objectives

Retrieve and analyze pizza order data.

Understand customer ordering behavior and sales performance.

Identify top-performing pizza types and categories.

Calculate key business metrics such as total revenue, average orders, and category-wise contribution.

## 📂 Dataset Information

The project is based on four main tables:

orders – Contains order details with date and time.

order_details – Includes information on quantity and pizza ordered.

pizzas – Contains pizza IDs, prices, and sizes.

pizza_types – Includes pizza names and categories.

## 🧩 Project Tasks

### Basic Queries

Retrieve the total number of orders placed.

Calculate total revenue generated from pizza sales.

Identify the highest-priced pizza.

Determine the most common pizza size ordered.

List the top 5 most ordered pizza types with their quantities.

### Intermediate Queries

Find the total quantity of each pizza category ordered (using joins).

Analyze the distribution of orders by hour of the day.

Calculate the category-wise distribution of pizzas.

Compute the average number of pizzas ordered per day.

Identify the top 3 most ordered pizza types based on revenue.

### Advanced Queries

Calculate the percentage contribution of each pizza type to total revenue.

Analyze cumulative revenue generated over time using CTEs.

Determine the top 3 most ordered pizza types based on revenue for each category (using window functions).

## 💻 Technologies Used

Database: MySQL

Tool: MySQL Workbench

Concepts Covered:

Joins (INNER, CROSS)

Aggregate Functions (SUM, COUNT, ROUND)

Common Table Expressions (CTE)

Window Functions (RANK, PARTITION BY)

Grouping and Sorting

## 📈 Key Insights

Identified top revenue-generating pizza types.

Determined the most demanded pizza sizes and categories.

Calculated the overall sales trend and cumulative revenue over time.

Highlighted top 3 pizzas per category contributing maximum revenue.
